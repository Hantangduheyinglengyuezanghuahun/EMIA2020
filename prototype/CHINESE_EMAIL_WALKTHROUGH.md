# Chinese email: complete source walkthrough

This update adds optional Simplified Chinese presentation while preserving the existing English default. The CLI selects the language; the original report measurements and screening rules remain unchanged. Chinese subject, text fallback, HTML, chart labels, dates and font are selected together. No AI, new dependency or treatment algorithm is introduced.

Modified behavior: the renderer can select a Chinese font and translate drawing text; compose_email can choose a Chinese subject and text alternative; html_body can return Chinese plain text when text_only is requested. The existing English routes remain available. Blank lines only separate code. Every added/replaced nonblank source line is listed below.
